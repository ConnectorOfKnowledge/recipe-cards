# Braised Chicken & Peppers with Pasta

A single-page recipe card. Dairy-free, one-pot, slow-cooked in a multi-cooker.

**Live:** https://connectorofknowledge.github.io/recipe-cards/

## Drop-in images

Place the following files in `images/` and they will appear automatically:

- `images/hero.jpg` — wide hero shot (16:10)
- `images/accent.jpg` — square accent shot (1:1)

If either file is missing, a placeholder block shows in its slot — the rest of the card stays intact.

## Stack

Single static `index.html`. No build step. Fonts via Google Fonts CDN.
